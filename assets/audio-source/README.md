# Original music

`tavern-dance.m4a` is the exact file the owner committed as `Tavern Dance.m4a`, created with Suno. It is retained here as the source and is not included in `dist/`.

The file contains stereo Opus audio in an MP4/M4A container. `npm run music:prepare` creates the compatible, quieter MP3 served by the game. See [audio notes](../../public/assets/audio/README.md).
