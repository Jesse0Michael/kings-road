# King’s Road surface textures

`tavern-table.webp` and `board-wood.webp` were generated specifically for this project with OpenAI image generation, then encoded as WebP for distribution. They are bundled assets; no generation service or CDN is contacted by the game.

The tavern table is an orthographic, diffusely lit dark timber surface. The board is a quieter continuous walnut/oak surface. The board’s numerals, castle, borders, and roads are drawn over the material in code, with a corresponding engraving height map. No game markings are baked into these source textures.
